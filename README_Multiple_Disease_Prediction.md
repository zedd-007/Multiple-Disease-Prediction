
# Multiple Disease Prediction using Machine Learning

## 📌 Project Overview
This project aims to predict multiple diseases such as diabetes, heart disease, and Parkinson’s disease using machine learning models. It is developed using Python and streamlines the end-to-end ML pipeline — from data preprocessing to prediction and evaluation.

## 💡 Features
- Predicts three diseases based on user inputs.
- Clean and modular code.
- Model evaluation and accuracy tracking.

## 🧰 Technologies Used
- Python
- scikit-learn
- Pandas
- NumPy
- Streamlit (for frontend interface)

## 🏁 Getting Started
1. Clone the repo:
```bash
git clone https://github.com/zedd-007/Multiple-Disease-Prediction.git
cd Multiple-Disease-Prediction
```
2. Install dependencies:
```bash
pip install -r requirements.txt
```
3. Run the app:
```bash
streamlit run app.py
```

## 📊 Model Details
- Diabetes: Logistic Regression
- Heart Disease: Random Forest
- Parkinson's: Support Vector Machine (SVM)

## 📎 Dataset Sources
- [Kaggle Diabetes Dataset](https://www.kaggle.com/datasets)
- [Heart Disease Dataset](https://www.kaggle.com/datasets)
